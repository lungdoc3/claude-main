# Domain Specifications
*One file per agent. Not yet populated — defining these is one of the core intellectual projects.*

---

The domain specs answer the question: what does each agent know, and what does it not know?

This is harder than it sounds. The edges are not obvious. Where does reptilian end and mammalian begin? What is cortical-only versus DMN-specific? The act of writing these specs will surface exactly where the theoretical understanding is solid and where it is hand-wavy.

Files to be created:
- `Layer1_Reptilian.md` — brainstem / survival hardware
- `Layer2_Mammalian.md` — limbic / relational programming  
- `Layer3_Cortical.md` — neocortex / rational processing
- `Layer4_Narrator.md` — default mode network / story of self

Start with Layer 1. Define the domain before worrying about training data. The corpus follows from the definition.
