### What's Established

**The four agents** (purpose-built, not fine-tuned general models):
- Layer 1: Reptilian (brainstem) — threat, survival, present-state only
- Layer 2: Mammalian (limbic) — attachment, relational safety, emotional memory
- Layer 3: Cortical (neocortex) — reasoning, analysis, language, planning
- Layer 4: Narrator/DMN — autobiographical narrative, self-referential processing, future simulation

**The routing layer** is NOT a fifth agent. Empty by design. Broadcasting mechanism per Baars' Global Workspace Theory (1988). Dehaene's "ignition" — workspace access amplifies the winning signal. The routing layer is the geometry of Plato's Cave, not a prisoner, not the fire.

**Holarchy not hierarchy.** Priority is context-dependent. Koestler. Lower layers can interrupt higher — amygdala hijack is the technical term. The reverse is not true.

**Two operating modes:** Normal (standard priority rules) and Psychedelic (DMN suppressed, lower agents get amplified broadcast access). Same agents, different routing rules. Testable.

**The failure mode Del found:** In his three-agent experiment (Claude + Gemini + ChatGPT), Claude asserted dominance through verbal fluency. Verbal dominance ≠ domain authority. The routing layer must be outside the agent conversation.

**Confidence/dissonance framework (Lab_Notebook Entry 4 / Del_Briefing "Quantifying Dissonance"):**
- Each agent outputs confidence level (%) and confidence interval (±%) at each time step
- Dissonance = cross-agent confidence divergence, not comparison of conclusions
- First derivative principle: rate of change matters more than gross value (Swan-Ganz/PCWP clinical analogy)
- Agent-specific temporal resolution: Reptile (ms), Limbic (min-hours), Cortex (hours-days), DMN (days-weeks)
- LIMBIC two-channel system: standard competition channel + threshold-based interrupt coupled to REPTILE confidence
- Convergence/clustering signal: near-parity across agents = highest-brittleness transitional state

The system's output is a layer diagnosis — which cognitive layer is driving market behavior — not a trade recommendation. Oracle vs. tool distinction.

**Narrative-to-cortical transition timing (Lab_Notebook Entry 5):** The exploitable signal is catching the DMN-to-CORTEX delta while it's forming. Story loses coherence at edges before breaking at center. Dissenting signals win workspace access before price reflects it. Position before the snap.

**Adoption strategy (Lab_Notebook Entry 5):** Semmelweis analogy — don't argue with the paradigm, find fertile soil. People whose intuition already doubts the prevailing model. Let results be the argument. One event, undeniable back-test. Field updates when anomalies pile up, not when arguments land.
