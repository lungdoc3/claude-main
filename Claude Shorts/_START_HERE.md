## The Project
**The Quadriune** — An animated short series using five characters to illustrate how the brain works. Educational. Scientifically accurate. Funny because it's true.

Scientific foundation: The Quadriune Brain Architecture (see Claude Brain project).

---

## The Concept
Five characters live inside a biological control room — the operational center of a human brain. Each episode begins with something happening in the outside world. What happens inside is the show.

**The Characters:**
- **REPTILE** — Brainstem/survival. Ancient, direct, no theory of mind for the others, no grudges, oddly lovable.
- **LIMBIC** — Limbic system/mammalian. Feels everything, remembers everything, catastrophizes in real time.
- **CORTEX** — Neocortex. Has the data. Closes laptop in frustration. Reopens it.
- **DMN** — Default Mode Network. Journaling in the corner. Thinks the story IS the system. Threatened by Psilo.
- **PFCL** — Prefrontal Cortex. Tries to run meetings. Realizes mid-meeting the meeting is the wrong format.

## Production Pipeline (Proposed)
1. **Character sheets** — Generate visual reference using Midjourney. One sheet per character showing multiple expressions/angles.
2. **Voice casting** — ElevenLabs for distinct character voices. Each character has a defined register.
3. **Animation** — Kling or Pika using character sheets as visual reference.
4. **Script → Video** — Full pipeline: script → voice generation → animation → assembly.

Randy already uses HeyGen for PsychedelicMD content. May be worth evaluating for this format too.
